Файл LoRa_Modulation ======================================

Содержит два проекта:
- LoRa2021_STM32F401RCT6 (передатчик)
- LoRa2021_STM32F411CEU6 (приемник)

Роль передатчика/приемника задается в app.c определением APP_ROLE_RX

Метод модуляции - lora.

Пример логов находятся в фалах RX_log.txt, TX_log.txt
